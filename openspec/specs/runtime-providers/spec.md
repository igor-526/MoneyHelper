# runtime-providers Specification

## Purpose
Абстракции времени и идентификаторов (`Clock`, `IdGenerator`), через которые `core` получает их без прямых вызовов, и их подключение через зависимости.
## Requirements
### Requirement: Протокол Clock
Система SHALL предоставлять протокол `Clock` с методом `now()`, возвращающим текущее время как aware-`datetime` в UTC.
Код в `core` MUST получать время только через `Clock` и MUST NOT вызывать `datetime.now()` напрямую.

#### Scenario: Боевая реализация возвращает aware-время в UTC
- **WHEN** вызывается `SystemClock.now()`
- **THEN** результат имеет `tzinfo`, равный UTC, и близок к текущему времени

#### Scenario: Fake-часы управляются тестом
- **WHEN** тест создаёт `FixedClock` с заданным моментом и вызывает `advance()` на интервал
- **THEN** `now()` возвращает заданный момент до `advance()` и момент, сдвинутый на интервал, после него

### Requirement: Протокол IdGenerator
Система SHALL предоставлять протокол `IdGenerator` с методом `new()`, возвращающим новый `UUID`. Код в `core` MUST
получать идентификаторы только через `IdGenerator` и MUST NOT вызывать `uuid4()` напрямую.

#### Scenario: Боевая реализация выдаёт уникальные UUID
- **WHEN** `UuidGenerator.new()` вызывается несколько раз
- **THEN** каждый результат является `UUID` версии 4 и все значения различны

#### Scenario: Fake-генератор детерминирован
- **WHEN** тест использует `SequentialIdGenerator` и вызывает `new()` несколько раз
- **THEN** значения выдаются в предсказуемом порядке и повторяются между запусками теста

### Requirement: Сущности не создают идентификатор и время сами
Базовые `Entity` и `TimestampMixin` MUST NOT содержать фабрик по умолчанию для `id` и `created_at`; эти значения
SHALL передаваться явно (их задаёт сервис через `IdGenerator` и `Clock`).

#### Scenario: Создание сущности без id
- **WHEN** сущность создаётся без указания `id`
- **THEN** создание завершается ошибкой валидации

### Requirement: Подключение провайдеров через зависимости
Реализации `Clock` и `IdGenerator` SHALL связываться с потребителями только в слое `depends/` через функции
`get_clock` и `get_id_generator`.

#### Scenario: Подмена провайдера в тесте
- **WHEN** тест переопределяет зависимость `get_clock` на `FixedClock`
- **THEN** обработчик получает `FixedClock` без изменения кода сервиса

# frontend-shell Specification

## Purpose
Переиспользуемые frontend-компоненты и типы общего назначения, которыми пользуются разделы кошельков, категорий,
операций, пополнений/переводов и аналитики: тип постраничного ответа `Page<T>` (зеркало backend `Page[T]`), выбор
валюты (`CurrencyPicker`, одиночный/множественный), выбор иконки из закрытого списка `BUSINESS_ICON_NAMES`
(`IconPicker`, `Drawer` на телефоне/`Modal` на широком экране), ввод денежной суммы без потери точности
(`MoneyInput`, значение всегда строка) и пустое состояние списка (`EmptyState`, без иллюстраций). Не затрагивает
навигацию/маршруты и backend — это делают задачи, которые эти компоненты используют.

## Requirements
### Requirement: Тип постраничного ответа `Page<T>`
`shared/api` SHALL экспортировать дженерик-тип `Page<T>` с полями `items: T[]`, `total: number`, `limit: number`,
`offset: number`, точно соответствующий форме ответа backend-схемы `Page[T]` (`core/schemas/pagination.py`). Любой
hook, читающий постраничный список (валюты и последующие кошельки/категории/операции/переводы), SHALL типизировать
ответ этим типом вместо собственного локального описания формы страницы.

#### Scenario: Использование в hook'е списка
- **WHEN** hook читает постраничный эндпоинт backend
- **THEN** тип ответа выражается как `Page<T>` с конкретным `T`, а не отдельным одноразовым интерфейсом

### Requirement: Выбор валюты — `CurrencyPicker`
`shared/ui` SHALL экспортировать компонент `CurrencyPicker` для выбора одной или нескольких валют из глобального
справочника (`GET /api/currencies`) через единственный проп `multiple?: boolean` (по умолчанию — одиночный выбор).
Список валют SHALL загружаться hook'ом `useCurrencies` (TanStack Query) без клиентской постраничной подгрузки —
запросом с максимально допустимым `limit` (100). Значение и обработчик изменения SHALL оперировать
идентификаторами валют (`id`): строкой в одиночном режиме, массивом строк — во множественном.

#### Scenario: Одиночный выбор
- **WHEN** `CurrencyPicker` отрисован без пропа `multiple` (или с `multiple={false}`) и пользователь выбирает валюту в списке
- **THEN** `onChange` вызывается один раз с `id` выбранной валюты строкой (не массивом)

#### Scenario: Множественный выбор
- **WHEN** `CurrencyPicker` отрисован с `multiple={true}` и пользователь выбирает несколько валют
- **THEN** `onChange` вызывается с массивом `id` всех выбранных валют, включая ранее выбранные

#### Scenario: Загрузка списка валют
- **WHEN** `CurrencyPicker` только что отрисован и ответ `GET /api/currencies` ещё не получен
- **THEN** компонент показывает состояние загрузки и не позволяет выбрать валюту до получения ответа

#### Scenario: Список валют получен
- **WHEN** `GET /api/currencies` вернул страницу валют
- **THEN** каждая валюта в выпадающем списке отображается по коду и названию (`code`, `name`), а число знаков после запятой (`decimalPlaces`) доступно вызывающему коду для выбранной валюты

#### Scenario: Ошибка загрузки списка валют
- **WHEN** `GET /api/currencies` завершился ошибкой
- **THEN** `CurrencyPicker` переходит в состояние «валюты недоступны» (поле недоступно для выбора), независимо от глобального уведомления об ошибке

### Requirement: Выбор иконки — `IconPicker`
`shared/ui` SHALL экспортировать компонент `IconPicker` для выбора одной иконки из закрытого списка
`BUSINESS_ICON_NAMES` (`shared/ui/icons.ts`), без добавления новых иконок в реестр. Компонент SHALL показывать
превью выбранной иконки через существующий компонент `Icon`. Контейнер выбора SHALL определяться шириной экрана
через `useIsMobile`: на телефоне — `Drawer`, на широком экране — `Modal`.

#### Scenario: Превью выбранной иконки
- **WHEN** `IconPicker` получил проп `value` с именем существующей бизнес-иконки
- **THEN** триггер выбора показывает эту иконку через `Icon`

#### Scenario: Нет выбранной иконки
- **WHEN** `IconPicker` получил `value = undefined`
- **THEN** триггер выбора не показывает иконку и сообщает, что иконка не выбрана

#### Scenario: Открытие на телефоне
- **WHEN** `IconPicker` открыт при `useIsMobile() === true`
- **THEN** список иконок показывается в `Drawer`

#### Scenario: Открытие на широком экране
- **WHEN** `IconPicker` открыт при `useIsMobile() === false`
- **THEN** список иконок показывается в `Modal`

#### Scenario: Выбор иконки из списка
- **WHEN** пользователь выбирает иконку в открытом `Drawer`/`Modal`
- **THEN** `onChange` вызывается с именем выбранной иконки и контейнер выбора закрывается

#### Scenario: Список ограничен бизнес-иконками
- **WHEN** `IconPicker` показывает список доступных иконок
- **THEN** список состоит ровно из `BUSINESS_ICON_NAMES`, без добавленных или отфильтрованных вручную имён

### Requirement: Ввод денежной суммы — `MoneyInput`
`shared/ui` SHALL экспортировать компонент `MoneyInput` — контролируемое поле ввода суммы, значение которого
MUST оставаться строкой на всём протяжении жизненного цикла компонента и никогда не приводится к типу `number`.
Поле SHALL принимать только цифры и не более одного разделителя дробной части. Необязательный проп
`decimalPlaces?: number` SHALL ограничивать число цифр после разделителя, когда он передан; без него ограничение
числа знаков на клиенте не применяется.

#### Scenario: Значение остаётся строкой
- **WHEN** пользователь вводит сумму в `MoneyInput`
- **THEN** значение, передаваемое в `onChange`, имеет тип `string` на любом шаге ввода

#### Scenario: Недопустимый символ отклоняется
- **WHEN** пользователь пытается ввести символ, не являющийся цифрой или разделителем дробной части (например, букву)
- **THEN** значение поля не изменяется и `onChange` с этим символом не вызывается

#### Scenario: Не более одного разделителя дробной части
- **WHEN** в поле уже есть разделитель дробной части и пользователь пытается ввести ещё один
- **THEN** значение поля не изменяется

#### Scenario: Ограничение числа знаков при известной валюте
- **WHEN** `MoneyInput` получил `decimalPlaces={2}` и пользователь пытается ввести третью цифру после разделителя
- **THEN** значение поля не изменяется

#### Scenario: Без ограничения знаков, когда валюта не выбрана
- **WHEN** `MoneyInput` отрисован без пропа `decimalPlaces`
- **THEN** число цифр после разделителя дробной части полем не ограничивается

### Requirement: Пустое состояние — `EmptyState`
`shared/ui` SHALL экспортировать компонент `EmptyState` для отображения пустого списка: обязательные иконка
(`Icon` по имени) и заголовок, опциональное текстовое описание, опциональная кнопка действия (подпись и
обработчик нажатия передаются вместе, одним объектом). Компонент MUST NOT использовать иллюстрации или другие
изображения, кроме иконок Lucide.

#### Scenario: Минимальный рендер
- **WHEN** `EmptyState` получил только `icon` и `title`
- **THEN** отображаются иконка и заголовок, без описания и без кнопки действия

#### Scenario: С описанием
- **WHEN** `EmptyState` получил проп `description`
- **THEN** описание отображается под заголовком

#### Scenario: С кнопкой действия
- **WHEN** `EmptyState` получил проп `action` с `label` и `onClick`
- **THEN** отображается кнопка с этой подписью, и её нажатие вызывает переданный `onClick`

#### Scenario: Без кнопки действия
- **WHEN** `EmptyState` получил `action = undefined`
- **THEN** кнопка действия не отображается

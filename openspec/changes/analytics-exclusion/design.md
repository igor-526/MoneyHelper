# Решение

Поле проходит через схему, сервис, доменную сущность и репозиторий. Фильтрация происходит до расчёта аналитики и курсов в SQL/fake. list_topup_legs_for_rates принимает include_excluded с default true для сохранения существующего поведения карточки кошелька; AnalyticsService передаёт false по умолчанию явно. История курсов получает тот же переключатель. Курсы продолжают рассчитываться по прежнему периоду: валютная модель не меняется. Frontend добавляет checkbox в формы и на страницу аналитики, включает значение в query key. Кэш аналитики инвалидируется существующими mutation hooks.

## Проверка
Unit-тесты граничных случаев, API-тесты и smoke при изменении контракта. QualityGate выполняется последовательно: make format, make lint, make test.

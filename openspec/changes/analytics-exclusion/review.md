# Ревью результата

Проверены границы параметров, сохранение изоляции воркспейсов и существующий путь обработки ошибок. Фильтрация списков выполняется до пагинации, list/count используют общие условия. Изменения не добавляют внешние зависимости в unit/smoke.

QualityGate: make format → make lint → make test прошёл последовательно. UI проверен автоматическими тестами в jsdom; проверка нативного календаря на физическом телефоне не выполнялась.

## Существенные проверки
- POST/GET/PUT расходов и пополнений сохраняют и сбрасывают флаг, обычные списки продолжают возвращать операции.
- Отмеченный расход исключается из агрегатов; отмеченное пополнение не даёт курс конвертации. При явном включении обе операции учитываются.
- Флаг включения работает во всех трёх режимах и входит в ключи кэша. Мутации инвалидируют также историю курса.
- Alembic видит единственный head `20261103_0014`; offline SQL добавляет колонку с DEFAULT false NOT NULL. На рабочую БД миграция не применялась.

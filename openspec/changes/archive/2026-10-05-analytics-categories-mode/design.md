## Решения

- **Диаграммы — Recharts.** React + SVG, поддержка React 19, `PieChart` и задел под столбцы и линии для будущих
  режимов; цвета задаём из токенов antd (`theme.useToken()`), жёстко заданных цветов нет (AGENTS.md).
- **«Весь период» — отсутствие параметров.** Backend без `date_from`/`date_to` не ограничивает выборку; курс усредняется
  по всем пополнениям воркспейса. Отдельного вычисления «диапазона воркспейса» нет — он совпадает с отсутствием границ.
- **Режимы — таблица `ANALYTICS_MODES`** (ключ, подпись, компонент), как `OPERATION_KINDS`; страница хранит режим и
  диапазон, режим сам запрашивает данные. Новый режим — новая строка.
- **Режим «Категории» использует существующий запрос** `group_by=category&type=expense` без `display_currency`:
  новый эндпоинт не нужен, сумма в валюте воркспейса — умолчание backend.
- **Итог «По всем категориям»** — точная сумма (BigInt, без `float`) уже округлённых сумм категорий, полученных от
  backend; отдельный запрос итога не делается.
- **Быстрые диапазоны — таблица `DATE_RANGE_PRESETS`.** Неделя считается с понедельника независимо от локали dayjs;
  «Неделя» и «Месяц» — полные календарные периоды (в том числе будущая часть).
- **Диаграмма:** не больше семи именованных секторов, остальное — «Прочие»; легенда с суммами и долями — HTML-список
  (он же табличное представление данных), цвета не единственный носитель идентичности.

## MODIFIED Requirements

### Requirement: Выбор валюты — `CurrencyPicker`
`shared/ui` SHALL экспортировать компонент `CurrencyPicker` для выбора одной или нескольких валют из глобального
справочника (`GET /api/currencies`) через единственный проп `multiple?: boolean` (по умолчанию — одиночный выбор).
Список валют SHALL загружаться hook'ом `useCurrencies` (TanStack Query) без клиентской постраничной подгрузки —
запросом с максимально допустимым `limit` (100). Значение и обработчик изменения SHALL оперировать
идентификаторами валют (`id`): строкой в одиночном режиме, массивом строк — во множественном. Компонент SHALL
принимать необязательный проп `allowedIds?: string[]`, ограничивающий список отображаемых опций переданным набором
id валют; при отсутствии этого пропа список опций SHALL оставаться полным (поведение без пропа не меняется).

#### Scenario: Одиночный выбор
- **WHEN** `CurrencyPicker` отрисован без пропа `multiple` (или с `multiple={false}`) и пользователь выбирает валюту в списке
- **THEN** `onChange` вызывается один раз с `id` выбранной валюты строкой (не массивом)

#### Scenario: Множественный выбор
- **WHEN** `CurrencyPicker` отрисован с `multiple={true}` и пользователь выбирает несколько валют
- **THEN** `onChange` вызывается с массивом `id` всех выбранных валют, включая ранее выбранные

#### Scenario: Загрузка списка валют
- **WHEN** `CurrencyPicker` только что отрисован и ответ `GET /api/currencies` ещё не получен
- **THEN** компонент показывает состояние загрузки и не позволяет выбрать валюту до получения ответа

#### Scenario: Список валют получен
- **WHEN** `GET /api/currencies` вернул страницу валют
- **THEN** каждая валюта в выпадающем списке отображается по коду и названию (`code`, `name`), а число знаков после запятой (`decimalPlaces`) доступно вызывающему коду для выбранной валюты

#### Scenario: Ошибка загрузки списка валют
- **WHEN** `GET /api/currencies` завершился ошибкой
- **THEN** `CurrencyPicker` переходит в состояние «валюты недоступны» (поле недоступно для выбора), независимо от глобального уведомления об ошибке

#### Scenario: Список опций без `allowedIds`
- **WHEN** `CurrencyPicker` отрисован без пропа `allowedIds`
- **THEN** список опций содержит все валюты, полученные от `GET /api/currencies`, — поведение совпадает с
  поведением компонента до появления этого пропа

#### Scenario: Список опций ограничен `allowedIds`
- **WHEN** `CurrencyPicker` отрисован с пропом `allowedIds`, содержащим подмножество id загруженных валют
- **THEN** список опций содержит только валюты с id из `allowedIds`, в том же порядке источника данных, остальные
  загруженные валюты не отображаются в списке выбора

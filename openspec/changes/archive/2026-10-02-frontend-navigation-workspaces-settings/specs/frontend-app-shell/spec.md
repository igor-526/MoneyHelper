## ADDED Requirements

### Requirement: Корневой маршрут и навигация
Приложение SHALL иметь защищённые маршруты `/wallets`, `/categories`, `/transactions`, `/transfers`, `/analytics` и
`/settings`; корневой маршрут `/` SHALL перенаправлять (с заменой записи истории) на `/wallets`. Навигация (нижняя
панель на телефоне, верхнее меню на широком экране) SHALL содержать ровно пункты «Кошельки», «Операции», «Аналитика»
и «Настройки» в этом порядке и MUST NOT содержать пункта «Главная». Приложение MUST NOT показывать статус
доступности backend и MUST NOT обращаться к `GET /health`. Неизвестный маршрут SHALL показывать страницу «Страница не
найдена».

#### Scenario: Корневой маршрут ведёт на «Кошельки»
- **WHEN** авторизованный пользователь с выбранным воркспейсом открывает `/`
- **THEN** он оказывается на `/wallets`, отображается раздел «Кошельки»

#### Scenario: Нет пункта «Главная»
- **WHEN** отображается навигация приложения
- **THEN** в ней четыре пункта «Кошельки», «Операции», «Аналитика», «Настройки», пункта «Главная» нет

#### Scenario: Нет статуса backend
- **WHEN** пользователь открывает любой раздел приложения
- **THEN** статус backend не отображается и запрос `GET /health` не выполняется

#### Scenario: Неизвестный маршрут
- **WHEN** пользователь открывает несуществующий путь
- **THEN** показывается страница «Страница не найдена»

## MODIFIED Requirements

### Requirement: Конфигурация окружения
Адрес backend SHALL задаваться переменной `VITE_API_URL`; в репозитории MUST лежать `frontend/.env.example` с переменной и значением для локальной разработки. Dev-сервер SHALL слушать порт 5173, совпадающий с `CORS_ORIGINS` backend.

#### Scenario: Локальный запуск
- **WHEN** запущены backend и `npm run dev`
- **THEN** страница по адресу `http://localhost:5173` выполняет запросы к API без CORS-ошибок

## REMOVED Requirements

### Requirement: Страница-заглушка и проверка backend
**Reason**: Решение пользователя: статус backend и «Главная» не нужны; корневой маршрут ведёт на «Кошельки».
**Migration**: Корневой маршрут и навигация описаны в требовании «Корневой маршрут и навигация»; управление
воркспейсами — в `frontend-workspaces` («Настройки»).

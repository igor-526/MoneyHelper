## ADDED Requirements

### Requirement: Средний курс кошелька
`GET /api/workspaces/{workspace_id}/wallets/{wallet_id}/rates` SHALL возвращать средний курс между валютами
кошелька, принадлежащего указанному воркспейсу текущего аутентифицированного пользователя, выведенный из ног всех
пополнений этого кошелька (без ограничения по диапазону дат). Курс между парой валют — простое арифметическое
среднее (не средневзвешенное) отношений `target_leg.amount / source_leg.amount` по всем пополнениям кошелька, у
которых есть нога и в исходной, и в целевой валюте (тот же принцип усреднения, что в аналитике, `analytics`).
`target_currency_id` — обязательный query-параметр, MUST входить в набор валют кошелька (`currency_ids`), иначе
запрос отклоняется. Валюта кошелька, для которой в истории пополнений нет ни одного подходящего пополнения с
ногой в обеих валютах, SHALL NOT получать искусственно подставленный курс — она перечисляется в
`unrated_currency_ids` ответа. Запрос без действительной сессии (без access-cookie) SHALL быть отклонён с ошибкой
аутентификации.

#### Scenario: Успешный расчёт курса для кошелька с двумя валютами
- **WHEN** аутентифицированный пользователь запрашивает `GET /api/workspaces/{workspace_id}/wallets/{wallet_id}/rates
  ?target_currency_id={target_currency_id}` для своего кошелька в воркспейсе `workspace_id` с валютами CNY и RUB
  (`target_currency_id` — RUB), и у кошелька есть хотя бы одно пополнение с ногами в обеих валютах
- **THEN** ответ 200 содержит `target_currency_id`, `rates` — список с одной записью
  `{currency_id: <CNY>, rate: <среднее RUB за CNY>}`, `unrated_currency_ids` — пустой список

#### Scenario: Курс усредняется по всем подходящим пополнениям
- **WHEN** у кошелька есть несколько пополнений с ногами в исходной и целевой валюте, с разным соотношением сумм
  в каждом
- **THEN** возвращённый `rate` равен простому арифметическому среднему отношений `target/source` по этим
  пополнениям (не средневзвешенному по суммам)

#### Scenario: Валюта без подходящих пополнений перечисляется отдельно
- **WHEN** у кошелька есть валюта, для которой ни одно пополнение не содержит одновременно ногу в ней и в
  `target_currency_id`
- **THEN** эта валюта отсутствует в `rates`, но присутствует в `unrated_currency_ids`; курс `1` не подставляется

#### Scenario: Кошелёк с одной валютой — пустой результат без ошибки
- **WHEN** аутентифицированный пользователь запрашивает курс для своего кошелька, у которого ровно одна валюта
  (совпадающая с `target_currency_id`)
- **THEN** ответ 200 с пустыми `rates` и `unrated_currency_ids`

#### Scenario: Отклонение `target_currency_id`, не входящего в валюты кошелька
- **WHEN** `target_currency_id` передан валютой, отсутствующей в `currency_ids` кошелька
- **THEN** ответ 400 с понятным сообщением

#### Scenario: Отклонение запроса без `target_currency_id`
- **WHEN** `GET .../wallets/{wallet_id}/rates` отправлен без query-параметра `target_currency_id`
- **THEN** ответ 400 с ошибкой валидации

#### Scenario: Несуществующий или чужой кошелёк
- **WHEN** `wallet_id` не существует в указанном воркспейсе, либо воркспейс `workspace_id` не принадлежит текущему
  пользователю
- **THEN** ответ 404, а не 403 — тот же принцип изоляции, что и у остальных эндпоинтов кошелька

#### Scenario: Отказ без аутентификации
- **WHEN** `GET .../wallets/{wallet_id}/rates` отправлен без действительного access-cookie
- **THEN** ответ 401

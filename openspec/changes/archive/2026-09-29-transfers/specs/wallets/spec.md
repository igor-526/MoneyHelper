## MODIFIED Requirements

### Requirement: Удаление кошелька
`DELETE /api/wallets/{wallet_id}` SHALL физически удалять кошелёк, принадлежащий текущему аутентифицированному
пользователю, вместе со всеми его записями о валютах, если у кошелька нет связанных операций и переводов. Если по
кошельку есть хотя бы одна операция (`transactions.wallet_id`) или хотя бы один перевод (`transfers.from_wallet_id`
или `transfers.to_wallet_id`), запрос SHALL быть отклонён с ошибкой конфликта, кошелёк не удаляется.

#### Scenario: Успешное удаление кошелька без операций и переводов
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/wallets/{wallet_id}` для своего кошелька, по
  которому нет ни одной операции и ни одного перевода
- **THEN** ответ 204, кошелёк и его записи о валютах удалены; последующий `GET /api/wallets/{wallet_id}` для того
  же `id` возвращает 404

#### Scenario: Удаление несуществующего кошелька
- **WHEN** `DELETE /api/wallets/{wallet_id}` отправлен с `wallet_id`, которого нет ни у одного пользователя
- **THEN** ответ 404

#### Scenario: Отклонение удаления кошелька с операциями
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/wallets/{wallet_id}` для своего кошелька, по
  которому есть хотя бы одна операция
- **THEN** ответ 409, кошелёк и его операции не удаляются

#### Scenario: Отклонение удаления кошелька с переводом
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/wallets/{wallet_id}` для своего кошелька,
  который является `from_wallet_id` или `to_wallet_id` хотя бы одного перевода
- **THEN** ответ 409, кошелёк и связанный перевод не удаляются

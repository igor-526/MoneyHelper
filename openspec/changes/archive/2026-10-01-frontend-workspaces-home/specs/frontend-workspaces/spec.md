## MODIFIED Requirements

### Requirement: Управление воркспейсами
Страница «Главная» (маршрут `/`, пункт навигации «Главная») SHALL содержать секцию управления воркспейсами:
список всех воркспейсов пользователя (`GET /api/workspaces`), для каждого — название, действие «Переключить»
(недоступно для уже текущего воркспейса), действие «Переименовать» (форма с одним полем названия,
`PUT /api/workspaces/{id}`) и действие «Удалить» (подтверждение `Popconfirm`, `DELETE /api/workspaces/{id}`, без
предупреждения о содержимом — удаление воркспейса на backend каскадное и безусловное), и действие создания
нового воркспейса (`POST /api/workspaces`). Успешное переключение SHALL обновить `WorkspaceContext` и сохранённый
в `localStorage` `workspace_id` без перезагрузки страницы; данные предыдущего воркспейса SHALL не отображаться
после переключения (запросы, зависящие от воркспейса, выполняются заново под новым `workspace_id`).

#### Scenario: Список воркспейсов на «Главной»
- **WHEN** пользователь открывает «Главную»
- **THEN** отображается секция со списком всех его воркспейсов и названием каждого

#### Scenario: Переключение воркспейса
- **WHEN** пользователь нажимает «Переключить» у воркспейса, отличного от текущего
- **THEN** этот воркспейс становится текущим (`WorkspaceContext` и `localStorage` обновлены), данные экранов
  (кошельки, категории, операции, переводы, аналитика) перезапрашиваются под новым `workspace_id`

#### Scenario: Переименование воркспейса
- **WHEN** пользователь переименовывает воркспейс через форму
- **THEN** запрос `PUT /api/workspaces/{id}` выполняется, список на «Главной» отображает новое название

#### Scenario: Удаление воркспейса
- **WHEN** пользователь подтверждает удаление воркспейса, отличного от текущего
- **THEN** запрос `DELETE /api/workspaces/{id}` выполняется, воркспейс пропадает из списка

#### Scenario: Создание нового воркспейса с «Главной»
- **WHEN** пользователь создаёт новый воркспейс через форму в секции управления
- **THEN** запрос `POST /api/workspaces` выполняется, новый воркспейс появляется в списке

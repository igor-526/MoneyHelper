## Why

Разделы кошельков, категорий, операций, пополнений/переводов и аналитики (задачи 014–018) независимо друг от друга
нуждаются в одних и тех же переиспользуемых кусочках интерфейса: типе постраничного ответа, выборе валюты, выборе
иконки, вводе денежной суммы без потери точности и пустом состоянии списка. Если не выделить их один раз сейчас,
каждая из следующих пяти задач будет реализовывать (и по-разному) одно и то же, что нарушает принцип единственной
ответственности и открытости/закрытости (AGENTS.md). Эта задача — единственный этап, который готовит фундамент
до начала работы над экранами.

## What Changes

- `shared/api/Page.ts` — новый TypeScript-тип `Page<T>` (`items`, `total`, `limit`, `offset`), соответствующий
  backend-схеме `core/schemas/pagination.py`; экспортирован из `shared/api`.
- `shared/ui/CurrencyPicker` — новый компонент выбора одной или нескольких валют (`multiple?: boolean`) поверх
  antd `Select`; данные берутся хуком `useCurrencies` (`useQuery` + `GET /api/currencies`).
- `shared/ui/IconPicker` — новый компонент выбора бизнес-иконки из уже существующего закрытого списка
  `BUSINESS_ICON_NAMES` (`shared/ui/icons.ts`) с превью через существующий `Icon`; на телефоне открывается в
  `Drawer`, на широком экране — в `Modal` (выбор по `useIsMobile`).
- `shared/ui/MoneyInput` — новый компонент контролируемого ввода денежной суммы; значение — всегда строка (никогда
  не приводится к JS `number`), опциональный `decimalPlaces` ограничивает число знаков после запятой.
- `shared/ui/EmptyState` — новый компонент пустого состояния (иконка, заголовок, опциональное описание,
  опциональная кнопка действия), без иллюстраций.
- Unit- и интеграционные тесты для всех перечисленных типов/hooks/компонентов.

Изменений в навигации, маршрутах и самих экранах приложения эта задача не вносит — их заводят задачи 014/016/018
при добавлении своих разделов (см. `docs/tasks/013_frontend_shell.md`, раздел «Контекст и решения»).

## Impact

- Новые файлы только внутри `frontend/src/shared/api/` и `frontend/src/shared/ui/` (плюс тесты рядом с кодом).
  Существующие файлы `shared/api/index.ts` и `shared/ui/index.ts` дополняются новыми экспортами.
- `frontend/src/app/navItems.ts` и `frontend/src/app/routes.tsx` — **не затрагиваются**.
- Backend, база данных и миграции Alembic — **не затрагиваются вовсе**, ни одного изменения. Используется только
  уже существующий и не требующий авторизации эндпоинт `GET /api/currencies` (`Page[CurrencyOut]`).
- Новых npm-зависимостей не требуется: используются уже установленные `antd` (`Select`, `Drawer`, `Modal`, `Input`),
  `@tanstack/react-query`, `lucide-react`.

## Non-goals

- Сами экраны кошельков/категорий/операций/пополнений-переводов/аналитики (014–018).
- Навигация и маршруты новых разделов — их заводит каждая из задач 014/016/018 самостоятельно.
- Мастер первичной настройки (онбординг) — решение дорожной карты: пустые состояния с призывом к действию на
  каждом экране вместо отдельного мастера.
- Ручная проверка PWA (задача 019) — эта задача её не выполняет и не изменяет PWA-конфигурацию.
- Новые бизнес-иконки — `BUSINESS_ICON_NAMES` не расширяется, `IconPicker` работает только с уже существующим
  закрытым списком.

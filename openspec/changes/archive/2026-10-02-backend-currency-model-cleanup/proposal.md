## Why

Задачи 024–029 перевели backend на новую валютную модель: у воркспейса основная валюта, у кошелька одна валюта,
пополнение — в двух валютах, расход — в валюте кошелька, переводы только между кошельками одной валюты, курс и
аналитика по пополнениям. Остатки старой модели (многовалютный кошелёк, `currency_ids`, «общая валюта» у переводов)
остались в документации, `openspec/config.yaml` (context, который читают все будущие агенты), AGENTS.md, README,
вводных частях основных specs и в неудачных именах кода. Они вводят в заблуждение и мешают начать frontend (031–035).

## What Changes

- Поиск и удаление остатков старой модели в коде, тестах, seed-данных, AGENTS.md, README, `openspec/config.yaml`,
  `openspec/specs/*`, `docs/`.
- AGENTS.md: раздел «Деньги и валюты» описывает новую модель (воркспейс, кошелёк, пополнение, расход, переводы,
  аналитика, баланс).
- `openspec/config.yaml`: context переписан под фактическое состояние (без `wallet_currencies`, `currency_ids`,
  «ног по каждой валюте кошелька»).
- Вводные разделы (Purpose) основных specs `wallets`, `transactions`, `transfers`, `analytics` приведены в
  соответствие с фактическим поведением; требования проверены на соответствие коду.
- Переименование `get_currency_ids` в `get_currency_id_by_wallet` (протокол, репозиторий, fake, сервис аналитики,
  тесты): метод возвращает одну валюту на кошелёк, прежнее имя наследовало многовалютную модель.
- Проверка отката и накатки миграций `0010`–`0012` на чистой временной БД; полный прогон QualityGate и `make test-infra`.

Изменений контракта API, схемы БД и поведения нет: миграции не добавляются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Требования основных specs соответствуют поведению; правятся только вводные разделы Purpose (они не являются
требованиями, поэтому delta-specs не нужны).

## Impact

- Документация: `AGENTS.md`, `README.md`, `openspec/config.yaml`, `openspec/specs/{wallets,transactions,transfers,analytics}/spec.md`,
  `docs/tasks/002_roadmap.md`.
- Backend: только переименование метода `get_currency_ids` (без изменения поведения).
- БД и API не меняются, миграция Alembic не нужна.

## Вне рамок

- Frontend (код и frontend-specs) — задачи 031–035.
- Исторические файлы задач `docs/tasks/001`–`029` и архив OpenSpec: фиксируют состояние на момент выполнения.
- Новая функциональность и изменение схемы БД.

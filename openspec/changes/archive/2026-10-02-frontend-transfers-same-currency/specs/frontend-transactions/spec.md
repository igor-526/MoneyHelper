## ADDED Requirements

### Requirement: Вкладки операций
Экран `/transactions` SHALL быть разделён на три вкладки — «Пополнение», «Расход» и «Перевод» (по умолчанию
«Пополнение»), заданные таблицей конфигурации `OPERATION_KINDS` (ключ, подпись, компонент содержимого), а не
ветвлением по ключу. Ключи вкладок: `topup`, `expense`, `transfer`. Активная вкладка SHALL отражаться в
query-параметре `tab`; неизвестное значение открывает вкладку по умолчанию. Каждая вкладка SHALL иметь собственный
список, фильтры, пагинацию, кнопку создания, редактирование и удаление; фильтры вкладки SHALL сохраняться при
переключении вкладок. Элементы управления SHALL быть не менее 44 px по высоте, формы на телефоне — в нижнем `Drawer`.

#### Scenario: Вкладка по умолчанию
- **WHEN** пользователь открывает `/transactions`
- **THEN** активна вкладка «Пополнение», выполняется `GET /api/workspaces/{workspace_id}/topups`

#### Scenario: Переключение на вкладку «Расход»
- **WHEN** пользователь выбирает вкладку «Расход»
- **THEN** выполняется `GET /api/workspaces/{workspace_id}/transactions`, адрес содержит `tab=expense`, показан
  список расходов со своими фильтрами

#### Scenario: Переключение на вкладку «Перевод»
- **WHEN** пользователь выбирает вкладку «Перевод»
- **THEN** выполняется `GET /api/workspaces/{workspace_id}/transfers`, адрес содержит `tab=transfer`, показан список
  переводов

#### Scenario: Вкладка из адреса
- **WHEN** пользователь открывает `/transactions?tab=transfer`
- **THEN** сразу активна вкладка «Перевод»

#### Scenario: Фильтры вкладки сохраняются
- **WHEN** пользователь задал фильтр на вкладке «Пополнение», перешёл на другую вкладку и вернулся
- **THEN** фильтр вкладки «Пополнение» сохранён

## REMOVED Requirements

### Requirement: Точка входа в раздел переводов со страницы «Операции»
**Reason**: переводы стали третьей вкладкой «Перевод» страницы «Операции», отдельная ссылка не нужна.
**Migration**: вкладка «Перевод» (`/transactions?tab=transfer`).

### Requirement: Вкладки «Пополнение» и «Расход»
**Reason**: заменено требованием «Вкладки операций» с третьей вкладкой «Перевод».
**Migration**: требование «Вкладки операций».

## ADDED Requirements

### Requirement: Хранение справочника валют
Система SHALL хранить глобальный справочник валют в таблице `currencies`: `id` (UUID, первичный ключ, значение
задаётся источником сидирования, а не генерируется БД), `code` (уникален, в верхнем регистре, до 10 символов),
`name`, `decimal_places` (целое число от 0 до 8 включительно — число знаков после запятой для сумм в этой валюте).
Справочник MUST NOT изменяться напрямую через API: единственный способ создать, изменить или переименовать валюту —
сидирование (см. capability `seeding`).

#### Scenario: Структура записи справочника
- **WHEN** в таблице `currencies` есть запись валюты
- **THEN** у неё заполнены `id`, `code`, `name`, `decimal_places`, и `code` совпадает со своим верхним регистром

### Requirement: Чтение списка валют
`GET /api/currencies` SHALL возвращать постраничный список валют из справочника в формате общей схемы `Page`
(`items`, `total`, `limit`, `offset`), принимая параметры пагинации через общую схему `PageParams` (`limit` 1..100,
по умолчанию 20; `offset` ≥ 0, по умолчанию 0). Элементы списка MUST быть отсортированы по `code`. Эндпоинт SHALL
быть доступен без авторизации: справочник валют не является данными конкретного пользователя.

#### Scenario: Список валют по умолчанию
- **WHEN** клиент запрашивает `GET /api/currencies` без параметров, а в справочнике три валюты (CNY, RUB, USDT)
- **THEN** ответ 200 содержит `items` из трёх валют, отсортированных по `code` (CNY, RUB, USDT), `total = 3`,
  `limit = 20`, `offset = 0`

#### Scenario: Поля элемента списка
- **WHEN** клиент получает элемент списка валют
- **THEN** элемент содержит `id`, `code`, `name`, `decimal_places` и не содержит служебных полей репозитория

#### Scenario: Пагинация применяется
- **WHEN** клиент запрашивает `GET /api/currencies?limit=1&offset=1`, а в справочнике три валюты
- **THEN** ответ 200 содержит один элемент (вторую по `code` валюту) и `total = 3`

#### Scenario: Некорректные параметры пагинации
- **WHEN** клиент запрашивает `GET /api/currencies?limit=0` или `GET /api/currencies?offset=-1`
- **THEN** ответ имеет код 400 с телом `{"detail": [...]}`

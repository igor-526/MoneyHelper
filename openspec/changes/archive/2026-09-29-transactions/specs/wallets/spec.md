## MODIFIED Requirements

### Requirement: Удаление кошелька
`DELETE /api/wallets/{wallet_id}` SHALL физически удалять кошелёк, принадлежащий текущему аутентифицированному
пользователю, вместе со всеми его записями о валютах, если у кошелька нет связанных операций. Если по кошельку
есть хотя бы одна операция (`transactions.wallet_id`), запрос SHALL быть отклонён с ошибкой конфликта, кошелёк не
удаляется.

#### Scenario: Успешное удаление кошелька без операций
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/wallets/{wallet_id}` для своего кошелька, по
  которому нет ни одной операции
- **THEN** ответ 204, кошелёк и его записи о валютах удалены; последующий `GET /api/wallets/{wallet_id}` для того
  же `id` возвращает 404

#### Scenario: Удаление несуществующего кошелька
- **WHEN** `DELETE /api/wallets/{wallet_id}` отправлен с `wallet_id`, которого нет ни у одного пользователя
- **THEN** ответ 404

#### Scenario: Отклонение удаления кошелька с операциями
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/wallets/{wallet_id}` для своего кошелька, по
  которому есть хотя бы одна операция
- **THEN** ответ 409, кошелёк и его операции не удаляются

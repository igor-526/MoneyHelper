## MODIFIED Requirements

### Requirement: Удаление категории
`DELETE /api/categories/{category_id}` SHALL физически удалять категорию, принадлежащую текущему
аутентифицированному пользователю, если у категории нет связанных операций. Если по категории есть хотя бы одна
операция (`transactions.category_id`), запрос SHALL быть отклонён с ошибкой конфликта, категория не удаляется.

#### Scenario: Успешное удаление категории без операций
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/categories/{category_id}` для своей категории,
  по которой нет ни одной операции
- **THEN** ответ 204, категория удалена; последующий `GET /api/categories/{category_id}` для того же `id`
  возвращает 404

#### Scenario: Удаление несуществующей категории
- **WHEN** `DELETE /api/categories/{category_id}` отправлен с `category_id`, которого нет ни у одного пользователя
- **THEN** ответ 404

#### Scenario: Отклонение удаления категории с операциями
- **WHEN** аутентифицированный пользователь отправляет `DELETE /api/categories/{category_id}` для своей категории,
  по которой есть хотя бы одна операция
- **THEN** ответ 409, категория и её операции не удаляются

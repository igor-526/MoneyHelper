# Мобильные даты и пагинация

## Зачем
Календарь диапазона и длинная пагинация выходят за узкий экран.

## Изменения
Раздельные поля дат на телефоне, календарь в пределах экрана; пагинация показывает текущую страницу и соседей, переходы на первую и последнюю, прокрутка только внутри панели.

## API и БД
Не меняются; миграция не требуется.

## Вне рамок
Поиск, мультивыбор и аналитика реализуются следующими этапами.

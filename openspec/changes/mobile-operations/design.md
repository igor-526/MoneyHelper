# Решение

Общий компонент диапазона использует два нативных поля даты на телефоне и RangePicker на широком экране. Выбор даты из пустого состояния задаёт однодневный диапазон, затем пользователь меняет другую границу; очистка поля снимает диапазон. Пагинация строит окно из текущей и соседних страниц; крайние кнопки ведут сразу на первую и последнюю. Стрелка отображается только когда соответствующая крайняя страница не входит в окно соседей (с третьей страницы от края). Все кнопки не меньше 44 px. Ширина ограничивается контейнером, overflow-x локален.

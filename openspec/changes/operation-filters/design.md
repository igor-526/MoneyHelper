# Решение

HTTP-схемы разбирают списки UUID. Сервис передаёт дополнительные параметры list/count, репозитории применяют одинаковые условия до пагинации. SQL использует icontains с autoescape для буквальных % и _. Fake повторяет семантику. Переиспользуемый компонент мультивыбора содержит checkbox Выбрать всё и кнопку Инвертировать. Поиск расположен отдельной строкой рядом с фильтром, чтобы вкладки не сжимали поле на телефоне. Смена поиска сбрасывает страницу; состояния сохраняются отдельно по вкладкам.

## Проверка
Unit-тесты граничных случаев, API-тесты и smoke при изменении контракта. QualityGate выполняется последовательно: make format, make lint, make test.

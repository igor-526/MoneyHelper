# Поиск и мультивыбор операций

## Зачем
Выполнение этапа задачи docs/tasks/036_improves.md.

## Изменения
Поиск комментария без учёта регистра по буквальной подстроке, объединённый через И с датами, кошельками и категориями. Внутри каждого мультивыбора действует ИЛИ. Выбрать всё включает все доступные значения, повторное снятие очищает выбор; Инвертировать выбирает дополнение.

## API и БД
GET transactions и topups: comment_query (до 1000 символов), wallet_ids/category_ids — UUID через запятую. Отсутствие списка означает все значения, пустая строка — пустой выбор (ноль результатов). Старые wallet_id/category_id сохраняются и комбинируются через И. Схема БД не меняется.

## Вне рамок
Авторизация, балансы, переводы и изменение валютной модели.

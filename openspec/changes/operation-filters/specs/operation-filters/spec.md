## ADDED Requirements

### Requirement: Поиск и мультивыбор операций
Система SHALL поддерживать следующее поведение: Поиск комментария без учёта регистра по буквальной подстроке, объединённый через И с датами, кошельками и категориями. Внутри каждого мультивыбора действует ИЛИ. Выбрать всё включает все доступные значения, повторное снятие очищает выбор; Инвертировать выбирает дополнение.

#### Scenario: Применение параметров
- **WHEN** пользователь применяет соответствующие параметры
- **THEN** результат соответствует выбранным значениям и остаётся ограничен текущим воркспейсом

#### Scenario: Чужой воркспейс
- **WHEN** запрос обращается к чужому воркспейсу
- **THEN** API возвращает 404

### Requirement: Контракт отбора операций
GET `/api/workspaces/{workspace_id}/transactions` и `/topups` SHALL принимать `comment_query` длиной до 1000 символов и списки `wallet_ids`/`category_ids` в формате UUID через запятую. Условия SHALL применяться до limit/offset и одинаково для items и total. Старые одиночные параметры SHALL сохранять поведение.

#### Scenario: Комбинация условий
- **WHEN** запрос содержит два кошелька, две категории, диапазон дат и строку поиска
- **THEN** ответ содержит только операции одного из выбранных кошельков, одной из выбранных категорий, в диапазоне дат и с буквальной подстрокой в комментарии без учёта регистра
- **AND** null-комментарии не соответствуют непустому поиску; `%` и `_` не являются шаблонами

#### Scenario: Пустой выбор
- **WHEN** wallet_ids или category_ids передан пустой строкой
- **THEN** ответ 200 содержит items=[] и total=0

#### Scenario: Ошибка параметров
- **WHEN** список содержит невалидный UUID или comment_query длиннее 1000 символов
- **THEN** API возвращает 400 с JSON detail

### Requirement: Состояние фильтров
Интерфейс SHALL хранить поиск и фильтры отдельно для каждой вкладки, сбрасывать страницу при изменении и применять черновик селекторов только по кнопке «Применить».

#### Scenario: Инверсия частичного выбора
- **WHEN** доступны A, B, C и выбраны A, C, пользователь нажимает «Инвертировать»
- **THEN** выбран только B

#### Scenario: Снятие всех пунктов
- **WHEN** все пункты выбраны и пользователь снимает галочку «Выбрать всё»
- **THEN** список выбранных значений пуст, после применения показывается пустой результат

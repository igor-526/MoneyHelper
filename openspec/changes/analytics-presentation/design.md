# Решение

Сохраняем buildDailySpending для статистики. Новая чистая функция spendingChartSeries строит отсортированный ряд непосредственно из buckets, не дополняя календарь. SpendingMode передаёт разные ряды графику и spendingStats. Строка Сумма вычисляется из существующего bigint total без float: для трат в валюте отображения, для курса как арифметическая сумма дневных значений. Итог категорий уже существует и не меняется.

## Проверка
Unit-тесты граничных случаев, API-тесты и smoke при изменении контракта. QualityGate выполняется последовательно: make format, make lint, make test.

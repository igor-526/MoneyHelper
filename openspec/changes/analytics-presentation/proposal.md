# Графики без пустых дат и суммы

## Зачем
Выполнение этапа задачи docs/tasks/036_improves.md.

## Изменения
График трат SHALL показывать только даты с операциями, сохраняя дни с нулевым итогом. Дневная статистика SHALL учитывать полный выбранный диапазон с нулевыми днями. Таблицы статистики трат и дневного курса SHALL содержать строку Сумма.

## API и БД
API и схема БД не меняются; миграция не требуется.

## Вне рамок
Авторизация, балансы, переводы и изменение валютной модели.

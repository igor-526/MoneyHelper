## MODIFIED Requirements

### Requirement: Карточка среднего курса кошелька
Для выбранного кошелька на экране операций SHALL отображаться карточка среднего курса через
`GET .../wallets/{id}/rates`. Она SHALL отображаться самостоятельно, без карточки баланса и без запроса endpoint
баланса.

#### Scenario: Выбран конкретный кошелёк
- **WHEN** пользователь фильтрует операции по одному кошельку
- **THEN** отображается средний курс кошелька, запрос баланса не выполняется

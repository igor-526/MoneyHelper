# 031. Навигация: убрать «Главную», воркспейсы в «Настройки»

Зависит от: 024. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md), раздел «Frontend».

## Цель
Убрать статус backend, удалить «Главную» и вернуть управление воркспейсами в «Настройки», добавив выбор валюты.

## Контекст и решения
- Решение пользователя: убрать информацию о доступности backend (`features/health`) и пункт «Главная». Корневой
  маршрут `/` перенаправляет на «Кошельки»; `navItems` содержит 4 пункта.
- Управление воркспейсами (`WorkspacesSection`) переносится на страницу «Настройки» (в 023 оно переехало на
  «Главную» — это обратный перенос).
- Форма создания воркспейса получает обязательный выбор валюты (024); у существующего воркспейса валюта
  показывается и не редактируется при наличии кошельков.
- Текущий воркспейс при этом переключается только из «Настроек»: нужен видимый индикатор текущего воркспейса в
  оболочке (заголовок/шапка), чтобы пользователь понимал, где находится; форма индикатора — design.md.
- Экран выбора воркспейса в `RequireWorkspace` (нет ни одного воркспейса) сохраняется и должен создавать
  воркспейс с валютой.
- Не забыть: правка UI проводится через OpenSpec-цикл, как и остальные.

## Объём
- Удаление `features/health`, пункта навигации, правка `routes.tsx`, `navItems`, тестов оболочки.
- Перенос `WorkspacesSection` в `SettingsPage`; поле валюты в `WorkspaceForm`.
- Тесты, включая мобильный и десктопный режимы.

## Критерии готовности
- Нет пункта «Главная» и упоминаний статуса backend; `/` ведёт на «Кошельки».
- Воркспейсами управляют в «Настройках», создание требует валюту.
- QualityGate проходит.

# 034. Переводы (frontend): одна валюта

Зависит от: 028, 033. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Форма перевода работает с кошельком одной валюты: сумма одна, валюта берётся из кошельков.

## Контекст и решения
- После выбора кошелька-отправителя список получателей ограничивается кошельками той же валюты; если таких нет —
  пустое состояние с пояснением, что конвертация делается через пополнение.
- Где живут переводы: третья вкладка страницы «Операции» либо прежний маршрут `/transfers` — решается в design.md
  (предпочтительно третья вкладка, чтобы все движения денег были в одном месте).

## Объём
- `TransferForm`, `TransferCard`, `TransfersPage`, хуки, типы, инвалидация балансов, тесты.

## Критерии готовности
- Перевод создаётся только между кошельками одной валюты, балансы обновляются.
- QualityGate проходит.

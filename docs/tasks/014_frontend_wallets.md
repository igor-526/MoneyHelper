# 014. Кошельки (frontend, этап F2b)

Зависит от: 013, 008. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Пользователь видит список своих кошельков и может создать, отредактировать и удалить кошелёк.

## Контекст и решения
- Список — карточки, не таблица (mobile-first правило AGENTS.md): иконка, название, валюты кошелька.
- Удаление, заблокированное существующими операциями (backend возвращает 409 `ConflictError`), должно давать
  понятное сообщение пользователю, а не общую ошибку.
- Набор валют кошелька — мультивыбор через `CurrencyPicker` (013), минимум одна валюта.
- Навигация — эта задача добавляет собственный пункт `navItems` («Кошельки») и маршрут `/wallets` (013 навигацию
  не трогает, см. её «Контекст и решения»); вставляется между «Главная» и «Настройки» — «Настройки» остаётся
  последним пунктом нижней панели (016/018 добавят свои пункты туда же, перед «Настройки»).

## Объём
- `navItems`/`routes.tsx` — пункт «Кошельки», маршрут `/wallets` под `RequireAuth`.
- Список кошельков (карточки) с пустым состоянием («Создать кошелёк») при отсутствии кошельков.
- Форма создания/редактирования: название, `IconPicker`, `CurrencyPicker` (мультивыбор).
- Удаление с подтверждением; обработка 409 (кошелёк с операциями) понятным сообщением без попытки повторного
  молчаливого удаления.
- Обработка стандартных ошибок API (400 валидации по полям, 401, 404, 500, сеть) по общему правилу AGENTS.md.
- Тесты компонентов и hooks.

## Вне рамок
Баланс кошелька по валютам (появится на экране операций, 016 — отображать баланс имеет смысл, когда есть
операции); переводы между кошельками (017).

## Открытые вопросы
Как показывать набор валют кошелька в карточке списка (коды текстом через запятую или чипы); порядок карточек в
списке (backend уже сортирует детерминированно по `created_at`, вопрос — только про визуальное представление).

## Критерии готовности
- Полный CRUD кошельков работает на телефоне и на широком экране.
- Ошибки (включая 409 при удалении с операциями) обрабатываются понятно.
- QualityGate проходит.

## Статус
Выполнено (изменение `frontend-wallets`, архив `2026-09-29-frontend-wallets`). `navItems`/`routes.tsx` дополнены
пунктом «Кошельки» между «Главная» и «Настройки» (исправлено при личной проверке propose-фазы — субагент изначально
предложил вставку после «Настройки»). Валюты кошелька — чипами `antd Tag`, в порядке, отданном backend, без
клиентской пересортировки. Один компонент `WalletForm` для создания и редактирования (`Drawer` на телефоне/`Modal`
на широком экране), открывается поверх списка без отдельного маршрута; редактирование не делает лишний `GET
/api/wallets/{id}` — значения берутся из уже загруженного элемента списка. Удаление — `Popconfirm`; 409 «есть
операции» не требует специальной обработки — общий обработчик ошибок уже показывает `error.detail` backend
(`MESSAGE_BUILDERS.conflict`). Тип `Wallet` — без camelCase-маппинга (в отличие от `Currency` из 013): поля не
участвуют в вычислениях на клиенте, маппинг не снимал бы реальной проблемы. Проверено полным QualityGate; backend
не затронут.

# 024. Основная валюта воркспейса

Зависит от: 020. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
У воркспейса появляется основная валюта (например RUB). Это опорная валюта для курсов, пополнений и аналитики
(задачи 025–030).

## Контекст и решения
- `workspaces.currency_id` — обязательное, внешний ключ на глобальный справочник валют (`ON DELETE RESTRICT`).
- Валюта указывается при создании воркспейса; в ответе API отдаётся `currency_id`.
- Смена валюты воркспейса, у которого уже есть кошельки, запрещается (`ClientError`): иначе все ранее сохранённые
  ноги пополнений и курсы теряют смысл. Переименование по-прежнему свободно. Вариант «менять можно, пока нет
  кошельков» — уточняется в design.md.
- Данных для переноса нет (решение пользователя): миграция очищает `wallets`, `transactions`, `transfers` и их
  зависимые таблицы, существующим воркспейсам выставляется валюта по умолчанию (RUB из сидов). Миграции в проекте
  содержат только схему, поэтому очистка и значение по умолчанию — явная, ревьюемая часть миграции с обоснованием в
  design.md.

## Объём
- Сущность, схемы, сервис, репозиторий, модель и миграция воркспейса: поле `currency_id`.
- Валидация существования валюты при создании; запрет смены валюты при наличии кошельков.
- Unit-, smoke- и infrastructure-тесты (миграция, RESTRICT).

## Вне рамок
Frontend (031); пересчёт старых данных.

## Критерии готовности
- Воркспейс нельзя создать без валюты или с неизвестной валютой.
- Валюту воркспейса с кошельками изменить нельзя.
- QualityGate проходит, включая `make test-infra`.

# 032. Кошельки (frontend): одна валюта

Зависит от: 025, 031. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Форма и карточки кошелька работают с одной валютой.

## Объём
- `WalletForm`: одиночный выбор валюты вместо мультивыбора; блокировка смены валюты у кошелька с операциями
  (по ошибке `400` и/или по признаку из ответа, решается в design.md).
- `WalletCard`, `WalletBalanceCard`: один баланс в валюте кошелька.
- Типы `Wallet`, хуки и тесты под новые контракты.
- Карточка среднего курса (`WalletRateCard`) адаптируется в 035.

## Критерии готовности
- Кошелёк создаётся и редактируется с одной валютой, баланс показан одной суммой.
- QualityGate проходит.

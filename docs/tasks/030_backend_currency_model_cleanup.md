# 030. Сверка backend и обновление документации

Зависит от: 024–029. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Закрыть backend нового валютного механизма: удалить остатки старой модели и обновить правила проекта.

## Объём
- Поиск и удаление остатков `currency_ids`, `wallet_currencies`, «ног по каждой валюте кошелька» в коде, тестах и
  seed-данных.
- Обновить раздел «Деньги и валюты» в AGENTS.md: у воркспейса основная валюта, у кошелька одна валюта, пополнение
  в двух валютах, расход в валюте кошелька, переводы между разными валютами, аналитика по курсу за диапазон.
- Актуализировать основные спецификации `openspec/specs/` (wallets, transactions, transfers, analytics,
  workspaces) и README.
- Полный прогон QualityGate и `make test-infra`, проверка отката и накатки миграций на чистой БД.

## Критерии готовности
- В коде и документации нет упоминаний многовалютного кошелька.
- QualityGate проходит.

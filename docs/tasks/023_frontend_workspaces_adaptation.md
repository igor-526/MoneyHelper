# 023. Адаптация frontend (воркспейсы, курс кошелька, комментарии)

Зависит от: 013–018, 020, 021, 022. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Frontend снова работает и даёт пользователю пользоваться всем, что появилось на backend после 018: воркспейсы
(020, breaking change путей API), средний курс кошелька (021), комментарии к операциям (022).

## Контекст и решения
- Задача 020 сознательно сломала существующий frontend (013–018): все пути API переехали под
  `/api/workspaces/{workspace_id}/...`. До этой задачи frontend нерабочий против текущего backend — это
  зафиксированное, осознанное состояние (см. `docs/tasks/020_workspaces.md`, раздел «Impact»).
- Точный объём (экран управления воркспейсами, переключатель текущего воркспейса, где в UI показывать курс
  кошелька, как выглядит поле комментария в форме операции) — уточняется при `/opsx:explore`/`/opsx:propose`, по
  аналогии с тем, как уточнялись открытые вопросы в 013–018.

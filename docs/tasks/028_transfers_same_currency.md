# 028. Переводы между кошельками одной валюты

Зависит от: 025. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md).

## Цель
Адаптировать переводы (011) к кошельку с одной валютой. Решение пользователя: перевод между кошельками разных
валют не поддерживается; конвертация валют происходит только через пополнение с указанием двух сумм (026).

## Контекст и решения
- Перевод допустим, только если валюты кошельков совпадают; иначе `ClientError`. Прежнее правило «хотя бы одна
  общая валюта» (`currency_id in from_wallet.currency_ids and in to_wallet.currency_ids`) заменяется на равенство
  `from_wallet.currency_id == to_wallet.currency_id`.
- Валюта перевода выводится из кошельков и в запросе не передаётся. Нужна ли колонка `transfers.currency_id` как
  денормализация или она удаляется (валюта берётся из кошелька при чтении) — решается в design.md; предпочтительно
  удалить, чтобы валюта не могла разойтись с кошельками.
- Раз валюту кошелька нельзя менять при наличии переводов (025), инвариант не нарушается после создания.
- Перевод не участвует в расчёте среднего курса: источник курса — только пополнения (026).
- Баланс: минус в отправителе, плюс в получателе, в валюте кошельков; `BalanceContributor` адаптируется под одну
  валюту без ветвления по виду.
- Миграция сбрасывает данные (см. 024).

## Объём
- Сущность, схемы, сервис, модель, миграция, репозиторий, роутер переводов.
- Адаптация `BalanceContributor`.
- Unit-, smoke- и infrastructure-тесты (отказ при разных валютах).

## Вне рамок
Переводы с конвертацией валют; frontend (034).

## Критерии готовности
- Перевод между кошельками разных валют отклоняется (`400`); одной валюты — проходит.
- Баланс обоих кошельков корректен.
- QualityGate проходит.

# Дорожная карта реализации MoneyHelper

Декомпозиция [основной задачи](001_main_task.md) на отдельные задачи `003`–`019`. Каждая задача передаётся в
`/opsx:explore` для детализации, затем в `/opsx:propose`. Архитектурные правила — в [AGENTS.md](../../AGENTS.md).
Задачи `003`–`012` закрывают backend и каркас frontend; `013`–`019` — экраны frontend для уже готового backend.

## Принятые решения

| Тема | Решение |
|---|---|
| Авторизация | JWT access + refresh (HS256, подпись `JWT_SECRET`), **токены на сервере не хранятся**; время жизни в `.env` (по умолчанию 15 минут и 30 дней); токены только в cookies, которые ставит и читает backend |
| Вход и регистрация | Вход по email; регистрация управляется флагом `REGISTRATION_ENABLED`; подтверждение email, сброс пароля, OAuth, роли и rate limit — вне рамок |
| Origin и CORS | Разные origin (same-site), CORS с `allow_credentials` и списком `CORS_ORIGINS`; CSRF закрывается проверкой `Origin` и JSON-only телом |
| Refresh | Скользящий: каждый `/refresh` выдаёт новую пару токенов. Отзыв без хранения токенов: у пользователя `token_version`, он лежит в claim refresh; logout и смена пароля увеличивают его и гасят все refresh пользователя. Окна терпимости нет |
| Frontend | React, полностью CSR, UI — Ant Design; mobile-first (проект в основном используется на телефоне), светлая и тёмная темы, PWA; каждое действие обрабатывает любую ошибку (400, 401, 403, 404, 409, 500, сеть) с уведомлением Toast |
| Тесты и CI | `make test` без БД (unit + smoke), тесты с БД в `tests/infrastructure/` через `make test-infra`; CI на GitHub: job без БД и job с PostgreSQL |
| Валюты | Глобальный справочник; сидируется при старте приложения в `lifespan`, не миграциями |
| Сидирование | Механизм в `utils`, данные в JSON, явные UUID, сгенерированные функцией |
| Пополнение | Это доход (в валюте воркспейса и валюте кошелька); перевод между кошельками — только одной валюты |
| Аналитика | Валюта отображения — необязательный GET-параметр (по умолчанию валюта воркспейса); курс — средний по пополнениям за диапазон анализа |
| Категории | Плоский список |
| Удаление | Физическое |
| Iconpack | Lucide; в БД хранится имя иконки |
| Архитектура | SOLID, по правилам из AGENTS.md; на ней строится скелет проекта |
| Frontend-декомпозиция (013–018) | По капабилити backend: кошельки → категории → операции → пополнения/переводы → аналитика; каждая задача самодостаточна и даёт рабочий экран |
| Навигация frontend-разделов | Нижняя панель вкладок на телефоне (существующий `navItems`/`useIsMobile`, ≤ 5 пунктов), верхняя навигация — на широком экране |
| Аналитика (frontend) | Сводные карточки/список сумм по корзинам среза, без графиков; графики и экспорт — отдельная будущая задача (как и на backend, 012) |
| Онбординг с пустыми данными | Пустые состояния с призывом к действию на каждом экране (кошельки, категории, операции); без отдельного мастера первичной настройки |
| Валютная модель (024–035) | У воркспейса основная валюта; у кошелька одна валюта (может совпадать с валютой воркспейса); пополнение — всегда в обеих валютах (одна, если совпадают), расход — в валюте кошелька; переводы только между кошельками одной валюты (конвертация — лишь через пополнение); аналитика — курс по пополнениям за диапазон анализа; старые данные сбрасываются миграцией; «Главная» и статус backend удаляются, воркспейсы — в «Настройки». Заменяет «кошелёк с несколькими валютами» из 008/011 |
| Воркспейсы | Несколько полностью изолированных рабочих пространств на пользователя (без совместного доступа); изоляция включает кошельки, категории, операции, переводы, балансы и аналитику — симметрично изоляции между пользователями |

## Валютная модель: порядок 024–035

Сначала полностью backend, затем frontend:

```
 024 валюта воркспейса ──► 025 кошелёк (1 валюта) ──┬──► 026 пополнения ──┐
                                                    ├──► 027 расходы ─────┴──► 029 аналитика/курс ──► 030 сверка
                                                    └──► 028 переводы (одна валюта) ───────────────────┘
 031 навигация/воркспейсы ──► 032 кошельки ──► 033 вкладки операций ──┬──► 034 переводы
                                                                      └──► 035 аналитика/курс
```

Задачи `031`–`035` начинаются только после `030`. Backend (024–030) реализован: эндпоинты `/topups`, `/transactions`
(расходы), `/transfers`; переводы не участвуют в курсе; `display_currency` — необязательный параметр аналитики.

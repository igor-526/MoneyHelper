# Создание приложения для ведения финансов в Китае
##  Основной контекст
Я для себя делаю приложения для ведения финансов. Уже сделал БД и backend шаблон
Рядом с папкой backend будет ещё и frontend, но для начала нам нужно сделать API
Суть приложения в следующем: я нахожусь в Китае и мне необходимо вести таблицу финансов
## Возможности
### Кошельки и финансы
У меня есть несколько кошельков:
- UPay в USDT
- Apipay CNY (2 шт)
- WeChatPay CNY (2 шт)
- NihaoChina CNY
- Наличка RUB
- и др
Нужна возможность администрировать валютами и кошельками для каждого пользователя отдельно
У каждого кошелька может быть одна или несколько валют
Это должно работать следующим образом:
Например, я пополняю кошелёк "AliPay Игорь", который привязан к валютам CNY и RUB.
Тогда при пополнении я должен обязательно указать обе валюты, чтобы потом считать курс
При этом необходимо иметь возможность держать кошелёк только с одной валютой
### Категории
Я должен иметь возможность добавлять категории как для доходов, так и для расходов. Для каждого кошелька должна быть возможность установки иконок. Для системы иконок нам необходимо заранее продумать iconpack, который потом будет использоваться на frontend и который мы потом сможем использовать в БД по какому либо идентификатору этой иконки
### Доходы и расходы
Я должен иметь возможность записывать доходы и расходы. Каждый должен быть привязан к конкретному кошельку
### Аналитика
У меня должна быть возможность посмотреть свои доходы и расходы в разных разрезах

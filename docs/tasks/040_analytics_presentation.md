# Даты графиков и суммы

Источник: [036_improves.md](036_improves.md).

## Объём
На графике только даты с операциями. Дневная статистика сохраняет нулевые дни полного диапазона. Добавить Сумма в таблицы статистики трат и курсов без float.

## Этапы
1. Описать proposal, design, spec и tasks в openspec/changes/analytics-presentation/.
2. Реализовать контракт и интерфейс, сохраняя изоляцию воркспейсов и обработку ошибок.
3. Проверить граничные случаи unit-тестами; изменения API покрыть smoke-тестами.
4. Последовательно выполнить make format, make lint, make test.
5. Провести ревью и зафиксировать результат.

## Приёмка
На графике только даты с операциями. Дневная статистика сохраняет нулевые дни полного диапазона. Добавить Сумма в таблицы статистики трат и курсов без float.
Ошибки запросов проходят через существующий глобальный обработчик. Интерфейс доступен от 320 px в обеих темах.

## Детали реализации
- Разделить данные представления графика и данные статистики: графику передавать только отсортированные buckets, статистике — существующий полный дневной ряд.
- Не удалять дату с операцией, итог которой округлился до нуля.
- Для заданного диапазона минимум, максимум, средняя и медиана по-прежнему учитывают все календарные дни, включая дни без операций.
- Для всего периода статистика использует интервал от первой до последней операции, как раньше.
- Добавить строку «Сумма» в статистику дневных трат и статистику дневного курса. Для курса это арифметическая сумма показанных дневных значений; существующая средняя не меняется.
- Суммировать десятичные строки через bigint с сохранением масштаба. Не использовать float для денежных вычислений.
- Сумма по категориям уже отображается в строке «По всем категориям» и сохраняется.

## Проверка
Пустой ряд, одна точка, несортированные даты, календарный разрыв, нулевой итог, точность 0.10 + 0.20, сохранение нулевых дней в средней и медиане. API и БД на этом этапе не меняются.

## Результат
Реализовано в изменении `analytics-presentation`. Итоговый QualityGate пройден: 464 backend-теста, 530 frontend-тестов. Статистика сохраняет полный диапазон, график — только даты операций. Ревью — `openspec/changes/analytics-presentation/review.md`.

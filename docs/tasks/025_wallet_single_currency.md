# 025. Кошелёк с одной валютой

Зависит от: 024. Дорожная карта: [002_roadmap.md](002_roadmap.md). Правила: [AGENTS.md](../../AGENTS.md), раздел «Деньги и валюты».

## Цель
У кошелька ровно одна валюта (может совпадать с валютой воркспейса). Отменяется модель «кошелёк с несколькими
валютами» из задач 008/011.

## Контекст и решения
- `Wallet.currency_ids: tuple[UUID, ...]` → `Wallet.currency_id: UUID`; таблица связи `wallet_currencies`
  удаляется, `wallets.currency_id` — обязательный внешний ключ (`ON DELETE RESTRICT`).
- Схемы создания/обновления и ответа: `currency_id` вместо `currency_ids`.
- Валюту кошелька нельзя менять, если у него есть операции или переводы (иначе суммы теряют смысл) — иначе свободно.
- Баланс кошелька (`GET .../wallets/{wallet_id}/balances`) становится одним числом в валюте кошелька; форма
  ответа (одна запись вместо списка или список из одного элемента) решается в design.md.
- Миграция сбрасывает данные (см. 024).

## Объём
- Сущность, протоколы (`WalletReader`/`WalletWriter`), сервис, модель, репозиторий, миграция, схемы, роутер.
- Адаптация `BalanceService` и протокола `BalanceContributor` под одну валюту.
- Обновление существующих unit-, smoke- и infrastructure-тестов.
- Эндпоинт среднего курса (021) в этой задаче не переделывается: он адаптируется в 029.

## Вне рамок
Правила операций (026–028), аналитика (029), frontend (032).

## Критерии готовности
- Кошелёк создаётся только с одной валютой; список валют в запросе отклоняется схемой.
- Смена валюты кошелька с операциями запрещена.
- QualityGate проходит, включая `make test-infra`.

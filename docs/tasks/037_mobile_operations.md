# Мобильные даты и пагинация

Источник: [036_improves.md](036_improves.md).

## Объём
Раздельные поля дат на телефоне, календарь в пределах экрана; пагинация показывает текущую страницу и соседей, переходы на первую и последнюю, прокрутка только внутри панели.

## Этапы
1. Описать proposal, design, spec и tasks в openspec/changes/mobile-operations/.
2. Реализовать контракт и интерфейс, сохраняя изоляцию воркспейсов и обработку ошибок.
3. Проверить граничные случаи unit-тестами; изменения API покрыть smoke-тестами.
4. Последовательно выполнить make format, make lint, make test.
5. Провести ревью и зафиксировать результат.

## Приёмка
Раздельные поля дат на телефоне, календарь в пределах экрана; пагинация показывает текущую страницу и соседей, переходы на первую и последнюю, прокрутка только внутри панели.
Ошибки запросов проходят через существующий глобальный обработчик. Интерфейс доступен от 320 px в обеих темах.

## Детали реализации
- На телефоне использовать два отдельных поля даты с подписями «Дата от» и «Дата до», без широкого всплывающего календаря диапазона.
- Значения — локальные календарные даты. Начальная граница передаётся как начало дня, конечная — как конец дня.
- Очистка любого поля снимает диапазон. Выбор первой даты из пустого состояния задаёт однодневный диапазон, затем можно изменить вторую границу.
- На широком экране сохранить RangePicker; определять режим через useIsMobile.
- Пагинация показывает только [current − 1, current, current + 1] в допустимых границах. Кнопки «Первая страница» и «Последняя страница» ведут к краям и появляются, только когда крайняя страница не входит в окно соседей; многоточия не нужны.
- Проверить страницы 1, 2, середину, предпоследнюю, последнюю и единственную страницу. Горизонтальная прокрутка допускается только внутри nav пагинации.

## Результат
Реализовано в изменении `mobile-operations`. Регрессионные тесты обновлены под нативные поля и кнопки пагинации. После совместной проверки со следующим этапом QualityGate пройден; подробности в `openspec/changes/mobile-operations/review.md`.

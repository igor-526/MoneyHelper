# Доработка функционала
## Контекст
За время использования продукта накопились некоторые доработки
## Доработки
### Фильтр дат
В мобильной версии не выбрать даты в операциях. Что то с вёрсткой
### Фильтр по описанию
Давай рядом с кнопкой фильтра добавим строку поиска. Она будет искать по описанию транзакции. Должно работать по логике "И" с остальными фильтрами
### Фильтры-селекторы
На данный момент в операциях есть фильтры по кошельку и категории. Они позволяют выбрать только одну категорию или кошелёк. Давай вместо этого сделаем мультивыбор этих категорий и кошельков. И туда добавим служебные пункты:
- "Выбрать всё" галочкой. При checked=true выбирается всё, при checked=false снимается выбор со всех пунктов
- "Инвертировать". Инвертирует весь выбор
### Флаг аналитики
Для операций необходимо добавить флаг "Не участвует в аналитике"
В аналитику должны по итогу попадать только те операции, у которых данный флаг не установлен
При этом в самой аналитике в фильтрах давай добавим ещё и флаг для игнорирования этого флага, чтобы мы всё таки могли анализировать включая эти операции. Но по умолчанию он отключен
### Пустые даты в аналитике
При выборе диапазона дат на графике отображаются абсолютно все даты. Я хочу, чтобы там были только те даты, у которых есть операции. Это не должно затронуть агрегации. В агрегации участвуют весь выбранный диапазон дат
### Сумма
Давай добавим в агрегирующие таблицы функцию "Сумма"
### Вёрстка пагинации
На мобильном устройстве в операциях внизу есть пагинация. При большом количестве страниц она выходит за пределы и появляется лишний горизонтальный скролл. Давай сделаем максимум 3 страницы и 2 управляющие кнопки
- если мы не на первой странице, то перед текущей страницей отображаем только одну страницу
- если мы не на последней странице, то после текущей страницы отображаем только одну страницу
- если мы на третьей и далее странице, то перед текущей страницей показываем только предыдущую страницу и стрелку перехода на первую
- аналогичная логика и с конца
- если панель пагинации выходит за горизонтальные пределы, то добавляем горизонтальный скролл только панели пагинации
